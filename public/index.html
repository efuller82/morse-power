Tutorial

What is Morse code?

Morse code is a secret way to send letters using short and long signals called dots (dits) and dashes (dahs).

You can hear Morse code as beeps, see it as flashes of light, or write it down on paper as dots and dashes.

Once you know the code, you can send a message with almost anything that can blink, beep, or click!

The secret is timing

Every dot and dash is built from a tiny unit of time. A dot (dit) is just 1 unit of sound. A dash (dah) is 3 units of sound — three times as long!

Inside one letter, there's a 1-unit pause between the beeps. Between letters, the pause is 3 units. Between whole words, it's an extra-long 7-unit pause. Listen and watch the lamp above to feel the difference.

How to play

Learn teaches you the alphabet a few letters at a time. Each short lesson works both ways — keying the code for a letter, and listening to code to name the letter — until the new letters feel like old friends.

Play puts 60 seconds on the clock. Translate as many letters as you can before time runs out. The fastest, most accurate players land on the top-10 high score list!
